ENVIRONMENT AND DEPENDENCIES
----------------------------
Recommended/tested interpreter: cv_venv, Python 3.12.10.
Installed there: opencv-contrib-python 5.1.0.95, NumPy 2.5.5,
Matplotlib 3.11.2, and pytesseract 0.3.13. Required OpenCV APIs
(CascadeClassifier and HOGDescriptor) are present; pip check reported no
broken requirements. OpenCV's bundled face, eye, and smile cascades are present.

The separate venv uses Python 3.14.2 and cannot import cv2. Do not use that
environment for these experiments. No existing environment was deleted or
modified. requirements.txt lists a compatible prebuilt-wheel dependency set
for Python 3.10-3.13; it was not installed during this repair.

pytesseract imports in cv_venv, but the external Tesseract executable was not
found. Install Tesseract separately and set TESSERACT_CMD if it is not on PATH.

IMAGE, VIDEO, AND OUTPUT CHECKS
------------------------------
sample.jpg exists and is 5184 x 2788 (width x height). input_video.mp4 exists
and is 1280 x 720, 30 fps, 902 frames. Outputs are saved under outputs/;
original input files were not overwritten.

  Experiments 32-34: test input 640 x 480 produced 640 x 480 images.
  Experiment 5 histogram graph: 1200 x 500 PNG.

No accidental output resizing, stretching, or cropping was observed. The
shared display helper scales down to at most 800 x 600 while preserving aspect
ratio; it does not change processing or saved-image resolution.

VIDEO VALIDATION
----------------
Experiment 26 output: 1280 x 720, 30 fps, 902 frames.
Experiment 39 output: 1280 x 720, 7.5 fps, 902 frames (4x slow motion).
For both videos the first output frame matched the final input frame (mean
absolute pixel difference 0.82), confirming reverse order. Temporary spooled
frames avoid retaining the complete decoded video in memory.

BLOCKERS AND REMAINING LIMITATIONS
----------------------------------
1. Experiment 25 cannot detect watches until both watch.jpg and a trained
   watch_cascade.xml are supplied.
2. Experiment 28 cannot detect vehicles until a trained vehicle cascade
   (haarcascade_car.xml) is supplied. No model was downloaded or substituted.
3. Experiments 27, 29, 30, and 38 need a representative, labeled face image to
   verify true-positive face/eye/smile detection. The available sample.jpg is
   a landscape and produced false-positive face boxes; those were not counted
   as successful detection.
4. Experiment 40 needs the external Tesseract OCR executable. Python package
   installation alone does not provide that executable.
5. Image display calls and size limits were verified through a GUI test shim;
   actual on-screen rendering was not manually verified. OpenCV's current build
   reports Windows UI support.

All available successful outputs are in outputs/. Seven experiments remain
blocked by missing model/media/executable/test-image prerequisites; their
status is not represented as a successful detection or OCR result.
